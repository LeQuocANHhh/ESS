# AGENTS.md

## 1. Project Context

Sales Insight Copilot is a learning project focused on data analysis, backend development, and applied AI.

## 2. Learning Principles

- Explain important technical decisions.
- Explain the logic before implementing code.
- Break complex tasks into smaller steps.
- Use beginner-friendly explanations.

## 3. Working Rules

- Inspect the existing project before modifying files.
- Read `docs/roadmap.md` before proposing the next phase.
- Do not recreate existing files.
- Do not delete or overwrite existing data without permission.
- Do not install dependencies without explaining why.
- Do not commit or push without user permission.

## 4. Reporting

After completing a task, report:

- Files created or modified.
- What was implemented.
- Important technical concepts.
- Tests or checks performed.
- Remaining issues.
